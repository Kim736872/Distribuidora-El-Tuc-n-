DISTRIBUIDORA EL TUCÁN — DEMOSTRACIÓN WEB

Archivos: index.html, styles.css, app.js y products.json.

Para probar localmente: abrir index.html en un navegador. Si el navegador bloquea fetch al abrir archivos locales, iniciar un servidor estático desde esta carpeta (por ejemplo: python -m http.server 8000) y visitar http://localhost:8000.

Para publicar en GitHub Pages: crear un repositorio, subir el contenido de esta carpeta a la raíz, abrir Settings > Pages, seleccionar Deploy from a branch, branch main y carpeta /(root), guardar. Esperar la URL de publicación.

IMPORTANTE:
- Los 83 productos se cargan desde el Excel que se encontró en la biblioteca.
- Los precios de demostración y las existencias deben confirmarse antes de uso comercial.
- Las imágenes actuales son ilustraciones locales por categoría (emojis/arte CSS), no fotografías de marcas. No dependen de enlaces externos y no se rompen. Para fotos exactas, se deben agregar imágenes propias/licenciadas dentro de assets y asociarlas a cada producto.
- El asistente es un prototipo local basado en reglas; no es un modelo de IA conectado.
- El checkout es ficticio: no cobra ni envía pedidos reales.
